# 05_longterm — resolution, TIE, 5-year mark

**Inputs**
- `04_filing/output/filing-plan.md`
- the resolution/archivo result + card issuance dates

**Process**
1. Track each submission: status, resolution, positive/negative silence.
2. After grant: schedule TIE card application + pickup (EX-17 + tasa 790-012, 1-month window).
3. Calendar the 5-year larga duración nacional mark (≈ Nov–Dec 2027; TP time counts per SEM 2/2026).

**Outputs** → `output/timeline.md` (resolution, TIE, larga duración mark, reminders)

**Human check** — calendar the larga duración mark; set alerts; re-verify SEM 2/2026 counting
with a lawyer before relying on the date.
