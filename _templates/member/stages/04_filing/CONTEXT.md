# 04_filing — tasas, forms, cita, file

**Inputs**
- `03_documents/output/checklist.md`
- `_shared/rules.md` (fees, forms, Mercurio mechanics)

**Process**
1. Select the official form (EX-25 / EX-99 / EX-17 whichever route) and the correct tasa
   (790-052 ep. / 790-012).
2. Prepare online filing steps (Mercurio, AutoFirma, provincia, notificaciones = adult
   representative's data).
3. Book the cita (cita previa; police station for TIE after grant).
4. Write the exact step order + payment records.

**Outputs** → `output/filing-plan.md`

**Human check** — book the cita, verify tasas/forms, confirm payment amounts before submitting.
