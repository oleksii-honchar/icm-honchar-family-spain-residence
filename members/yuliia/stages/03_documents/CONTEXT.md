# 03_documents — build the document checklist

**Inputs**
- `02_route/output/route.md` — chosen route determines the doc set
- `_shared/membership.md` Paperless index (doc ids)
- Paperless (mint)

**Process**
1. Derive the required document list for the chosen route (form annexes + evidentiary docs).
2. For each document: status — ready (paperless id / on hand) or GAP (to gather).
3. Flag cross-member dependencies (e.g. Artem's father consent, Yuliia's docs).

**Outputs** → `output/checklist.md` (per-doc status table, sources, GAPs)

**Human check** — gather missing documents; confirm GAPs are real, not just absent from paperless.
